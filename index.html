Repairing a broken JSON file

A 183 KB API response with 300 records would not parse. I located each error, fixed it without touching the data, and validated the result.

Seven syntax errors found and fixed; all 300 records kept.

Three missing commas, two single-quoted keys and two unquoted keys. A short script reported the failing line each time, so every fix was checked before moving on.

A FastAPI service that merges four config layers

One endpoint, /effective-config, combines defaults, a YAML file, a .env file and OS environment variables. Query parameters like ?set=port=9000 override everything else.

Later layers always win, and the API key is never exposed.

Ports and worker counts are converted to integers, debug to a boolean, and api_key always comes back as "****". NUM_WORKERS in the .env file maps to workers, and CORS is open so a browser page can call it directly.

defaults  <  config.development.yaml  <  .env  <  APP_* env vars  <  ?set=key=value

GET /effective-config
{"port": 8782, "workers": 1, "debug": true,
 "log_level": "debug", "api_key": "****"}

A shell script that reorganizes files by category

Thirty text files were spread across nested folders. Each one declares its category on its first line, and the script moves it to {category}/{path-with-dashes}-{filename}.

30 files moved, including names with spaces and accents.

Paths are quoted throughout, categories such as café, münchen and 日本語 are preserved byte for byte, and a dry-run flag previews every move before anything changes.

docs/part 2/file30.txt   →   café/docs-part 2-file30.txt

Delhi revenue for May 2025

From a 143-row sales file, I kept the Delhi transactions dated May 2025 and summed quantity times price.

Four transactions add up to 11,457.25, which rounds to 11,457.

I first checked for missing values, duplicate rows and spelling variants of city names, and found none, so no cleaning was needed.

Revenue = SUM(quantity × price)
        = 2,541.75 + 3,830.56 + 1,497.44 + 3,587.50
        = 11,457.25
